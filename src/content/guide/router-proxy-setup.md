## 直接结论

如果家里有电视盒子、投影仪、游戏主机这类不方便单独安装客户端的设备，想让它们和手机、电脑一样自动走代理，就需要在路由器这一层解决，而不是继续给每台设备单独装 Clash 或 sing-box。常见做法分两种：把主路由刷成支持代理插件的第三方固件，或者用一台闲置设备搭建"旁路由"，让主路由把流量转发过去。两种思路各有取舍，没有哪一种绝对更好，需要结合你的路由器型号、动手能力和风险承受度来选。

## 两种思路怎么选：对比表

| 维度 | 主路由刷固件 | 旁路由分流 |
| --- | --- | --- |
| 基本原理 | 把路由器原厂固件替换为支持代理插件的第三方固件（如梅林、爱快、OpenWrt） | 主路由不动，用另一台设备（软路由主机、闲置电脑、树莓派等）跑代理，主路由通过网关或策略路由把流量导过去 |
| 需要的硬件 | 现有路由器（前提是型号在支持列表内） | 额外一台可以长期运行的设备，外加原有路由器 |
| 配置难度 | 中等，主要难点在刷机本身 | 较高，涉及网段划分或策略路由 |
| 对主网络的影响 | 刷机失败可能导致路由器无法正常联网（俗称"变砖"），需要有恢复手段 | 主路由固件不变，出问题直接断开旁路由即可恢复，风险更可控 |
| 适合人群 | 路由器型号明确支持第三方固件、能接受一定折腾成本的用户 | 已经有闲置设备、不想改动现有路由器配置的用户 |

## 主路由刷固件：大致步骤

1. 先查清楚自己路由器的具体型号，确认它在目标固件（梅林改版、爱快、OpenWrt 等）的官方支持列表里，型号不匹配硬刷是变砖的主要原因。
2. 刷机前备份原厂固件和现有的网络配置，方便出问题时回退。
3. 只从固件项目的官方渠道下载文件，避免来源不明的修改版固件。
4. 刷入支持代理插件（如 PassWall、ShadowSocksR Plus+ 等）的固件后，导入机场的订阅链接，并参考[Clash分流规则](/guide/clash-rules-guide/)里介绍的思路配置国内直连、境外代理的规则。
5. 配置完成后，用家里不同类型的设备逐一测试，确认规则生效。

## 旁路由分流：大致步骤

1. 准备一台可以长期开机运行的闲置设备，性能要求不高，但网卡稳定性要好。
2. 在这台设备上安装支持代理的系统（常见的是 OpenWrt 或爱快），并配置好代理客户端。
3. 让主路由把网关或部分设备的流量指向旁路由的地址，具体做法有"改主路由 DHCP 网关"和"按需做策略路由"两种，后者更灵活但配置也更复杂。
4. 主路由固件全程不需要改动，遇到问题只要把网关改回主路由本身，就能立刻恢复到没有代理的状态。

## 适用场景

- 家里有多台不方便单独装客户端的设备（智能电视、投影仪、游戏主机等），且已经确认会长期使用某个机场。
- 已经在用[TUN模式](/guide/tun-mode-explained/)覆盖电脑上的应用，但个别智能家居设备始终无法单独配置代理。
- 愿意接受一次性的配置成本，换取"设置好之后全屋自动生效"的省心体验。

不适合的情况：只有一两台设备需要用、经常更换居住地点和网络环境、或者还没确定要不要长期使用代理服务。这类情况直接在设备上装[Clash客户端](/guide/clash-basics/)或[sing-box](/guide/singbox-basics/)，配置和迁移都更简单。

## 需要注意的事项

- **路由器性能是瓶颈**：入门级路由器的处理器性能有限，加解密开销会占用较多资源，实际速度可能不如直接在电脑上跑客户端，尤其是同时接入设备较多的时候。
- **DNS 容易被忽略**：路由器层如果没有正确接管 DNS 查询，仍然可能出现[DNS泄露](/airport/what-is-dns-leak/)，也就是代理生效了但域名解析请求还是走了本地运营商，这一点需要单独检查，不能只看能不能打开网页。
- **IPv6 环境要格外留意**：如果家里的宽带同时分配了 IPv6 地址，而代理规则只处理了 IPv4，部分支持 IPv6 的应用可能会绕开代理直接走 IPv6 线路，这也是路由器代理里最常被忽略的漏洞之一。
- **请遵守你所在地区的法律法规。**

## 自己怎么验证是否真的生效

1. 用一台已知没有单独装客户端的设备（比如电视盒子）访问平时无法打开的网站，确认能不能直接访问，这样才能确定代理是在路由器层生效，而不是设备本身另有配置。
2. 在两台不同设备上分别访问出口 IP 检测网站，对比配置前后的 IP 和归属地是否发生变化，避免只测一台设备得出片面的结论。
3. 参考[DNS泄露](/airport/what-is-dns-leak/)里介绍的方法，专门检查一次 DNS 解析结果，确认查询确实经过了代理节点。
4. 主动制造一次"回退"：临时断开旁路由或把网关改回主路由，确认设备的网络能立刻恢复正常，验证这套方案是可控、可回退的，而不是只能靠重新刷机才能恢复。

## 刷机出问题之后怎么办

主路由刷固件最让人担心的是"变砖"，也就是刷完之后路由器无法正常启动或联网。真正遇到这种情况时，先不要慌张地反复重刷：

- 大部分支持第三方固件的路由器都保留了恢复模式（常见做法是长按 Reset 键或断电重启若干次），先查清楚自己型号的具体恢复方法，而不是凭印象操作。
- 恢复模式通常允许重新刷入官方原厂固件，回到出问题之前的状态，这也是刷机前一定要先备份原厂固件的原因。
- 如果自己不确定某一步操作是否安全，先在网上查一下同型号其他用户的经验，机型和固件版本对不上是出问题的主要原因，不要跨太多版本盲目尝试。

旁路由方案在这方面天然更省心，因为主路由固件全程没有改动，出问题只需要把网关指回主路由，几乎不存在"回不去"的风险，这也是很多人愿意多花一份硬件成本选择旁路由的原因。

## 检查清单

- [ ] 路由器或旁路由设备的型号已确认在目标固件的支持列表内
- [ ] 已备份原厂固件或现有网络配置
- [ ] 固件和插件都来自官方渠道下载
- [ ] 分流规则已经和平时使用习惯保持一致
- [ ] 已单独检查过 DNS 解析是否经过代理
- [ ] 已用两台不同设备完成出口 IP 对照测试
- [ ] 清楚知道出问题后如何在几分钟内回退到原状态
